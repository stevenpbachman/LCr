# 'tdwg_level3'

A dataset used internally by the LCr package. WGSRPD L3 TDWG values with
geometry

## Usage

``` r
tdwg_level3
```

## Format

A data frame with 369 rows and 5 variables:

- LEVEL3_NAM:

  chr

- LEVEL3_COD:

  chr

- LEVEL2_COD:

  dbl

- LEVEL1_COD:

  dbl

- geometry:

  MULTIPOLYGON
