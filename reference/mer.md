# Minimum Enclosing Rectangle (mer)

Calculates the minimum enclosing rectangle (mer) from a set of points
(x,y)

## Usage

``` r
mer(thepoints)
```

## Arguments

- thepoints:

  dataframe of points ie c(x,y)

## Value

vector of 4 doubles = xmin,xmax,ymin,ymax

## Details

calculates the MER of a set of numbers'
