# 'tdwg2iucn'

A dataset used internally by the LCr package. Maps WGSRPD L3 TDWG values
to IUCN land region values

## Usage

``` r
tdwg2iucn
```

## Format

A data frame with 866 rows and 5 variables:

- ID:

  dbl

- Level.3.code:

  chr

- TDWG_Name:

  chr

- countryoccurrence.countryoccurrencesubfield.countryoccurrencename:

  chr

- countryoccurrence.countryoccurrencesubfield.countryoccurrencelookup:

  chr
