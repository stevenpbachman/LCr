# True centre of gravity from a set of Lat longs

Calculates the "true" centre of gravity (weighted) from a set of lat
longs, using cartesian geometry. Used as part of the projection wizard.

## Usage

``` r
trueCOGll(thepoints)
```

## Arguments

- thepoints:

  set of points c(lat,long)

## Value

a point (lat,long) from centre
