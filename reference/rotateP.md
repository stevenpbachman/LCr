# Rotates a set of points

Rotates a set of point by an angle in radians. Used as part of the AOO
rotation calculations.

## Usage

``` r
rotateP(thepoints, angle)
```

## Arguments

- thepoints:

  set of points in metres i.e. c(x,y)

- angle:

  in radians

## Value

dataframe of points
