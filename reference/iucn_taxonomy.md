# 'iucn_taxonomy'

A dataset used internally by the LCr package. Provides upper level
taxonomic ranks used by IUCN Red List

## Usage

``` r
iucn_taxonomy
```

## Format

A data frame with 3942 rows and 5 variables:

- family:

  chr

- kingdom:

  chr

- phylum:

  chr

- classname:

  chr

- ordername:

  chr
