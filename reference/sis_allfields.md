# Generate the allfields.csv file

Generate the allfields.csv file

## Usage

``` r
sis_allfields(unique_id, occs = NULL)
```

## Arguments

- unique_id:

  (character) Unique identifier.

- occs:

  (data frame) Cleaned GBIF occurrence file in DWCA format. See
  clean_occs() function.

## Value

Returns an SIS compliant data frame
