# Geographic coordinates to cartesian (x,y,z)

Calculates the Cartesian coordinates (x,y,z) from lat long in radians.
Used as part of the projection wizard.

## Usage

``` r
ll2cart(latr, longr)
```

## Arguments

- latr:

  latitude point in radians

- longr:

  longtitude point in radians

## Value

dataframe of x,y,z
