# Cartesian coordinate projection

Used as part of the projection wizard, calculates Cartesian (x,y,z),
projected from the centre of the sphere to the earth surface, returns
cartesian coordinates (x,y,z)

## Usage

``` r
pro2sph(x, y, z)
```

## Arguments

- x:

  East to West coordinate in metres

- y:

  South to North coordinate in metres

- z:

  height coordinate in metres

## Value

x,y,z
