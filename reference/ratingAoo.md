# IUCN rating based on AOO Area

Calculates IUCN rating based on Area of occupancy (AOO) in km2

## Usage

``` r
ratingAoo(AOOArea, abb = TRUE)
```

## Arguments

- AOOArea:

  Area in km2

- abb:

  abbreviation TRUE or FALSE , TRUE = 2 letter code, FALSE = full text
  (default = TRUE)

## Value

Text one of CR, EN, VU, NT, LC or Critically Endangered, Endangered,
Vulnerable, Near Threatened, Least Concern
